ALONA & NIKKI – SITE

Preview locally: open index.html in a web browser.

Publish for free on GitHub Pages:
1. Sign in or create a free GitHub account at github.com.
2. Create a PUBLIC repository called alona-nikki (or any name).
3. Upload index.html and the assets folder with its two .webp images to the repository root.
4. Go to Settings > Pages > Build and deployment > Deploy from a branch.
5. Select main and /(root), then Save.
6. Wait for the published address: https://YOUR-USERNAME.github.io/alona-nikki/

IMPORTANT PRIVACY NOTE: A public GitHub Pages site and its source files are publicly accessible, even though the page asks search engines not to index it. The WhatsApp number is embedded in the button URL. Do not upload passports, IDs, income statements, or other private documents.

To change WhatsApp number, edit the href starting with https://wa.me/ in index.html.
